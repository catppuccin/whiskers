These are all of the functions available to use in your templates, alongside all
of the [existing Tera built-ins](https://keats.github.io/tera/docs/#built-ins).

## `if` {#functions-if}

- **Description**: Return one value if a condition is true, and another if it's false.
- **Example**: `if(cond=true, t=1, f=0)` ⇒ `1`

## `object` {#functions-object}

- **Description**: Create an object from the input.
- **Example**: `object(a=1, b=2)` ⇒ `{a: 1, b: 2}`

## `css_rgb` {#functions-css_rgb}

- **Description**: Convert a color to an RGB CSS string.
- **Example**: `css_rgb(color=red)` ⇒ `rgb(210, 15, 57)`

## `css_rgba` {#functions-css_rgba}

- **Description**: Convert a color to an RGBA CSS string.
- **Example**: `css_rgba(color=red)` ⇒ `rgba(210, 15, 57, 1.00)`

## `css_hsl` {#functions-css_hsl}

- **Description**: Convert a color to an HSL CSS string.
- **Example**: `css_hsl(color=red)` ⇒ `hsl(347, 87%, 44%)`

## `css_hsla` {#functions-css_hsla}

- **Description**: Convert a color to an HSLA CSS string.
- **Example**: `css_hsla(color=red)` ⇒ `hsla(347, 87%, 44%, 1.00)`

## `read_file` {#functions-read_file}

> [!WARNING]
> Ensure input file and template have the same line ending format as to avoid mixing line endings in the output file.
>
> This is a rare bug that only happens in specific circumstances and should not happen if you open and save both files in the same editor.

- **Description**: Read and include the contents of a file.
- **Attributes**
  - **`path`**: `string`
    - **Description**: Path to the file to read, relative to the template file.
  - **`start_line`**: `u64` (1-based)
    - **Description**: First line to read.
    - **Default**: `1`
  - **`end_line`**: `u64`
    - **Description**: Last line to read (inclusive).
    - **Default**: Last line of the file
- **Examples**
  - `read_file(path="abc.txt")` ⇒ `abc`
  - `read_file(path="abc.txt", first_line=1, last_line=1)` ⇒ `abc`
